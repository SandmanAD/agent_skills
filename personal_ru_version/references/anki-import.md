# Импорт и шаблон Anki

Официальная справка: https://docs.ankiweb.net/importing/text-files.html
При спорных настройках сверяй актуальную документацию. Не подменяй тип записи названием колоды: это разные настройки.

Ниже `<Язык>` — имя первого поля (German, French, Czech…), как в CSV. В выдаваемой пользователю инструкции подставь реальные имена.

## Новый тип записи

Tools → Manage Note Types → Add → Clone: Basic (and reversed card). Назови тип по языку (например, «Deutsch»).
В Fields переименуй Front в `<Язык>`, Back в Russian;
добавь `<Язык> Example`, Russian Example, Transcription в этом порядке.
Две карточки на запись: `<Язык>` → русский и русский → `<Язык>`. Если пользователь
хочет только одно направление — клонируй обычный Basic.
Для каждого языка — отдельный тип: изменение шаблона одного языка не затронет другие.
Для существующего типа добавь только недостающие поля.

## Дизайн карточек

Готовый дизайн лежит в `assets/design/`: `front.html`, `back.html` (первый шаблон),
`reverse_front.html`, `reverse_back.html` (второй шаблон, обратная карточка) и `card.css`.

- Лицо: подпись направления («IT → RU»), слово, IPA. Пример на лице не показывается.
- Оборот: перевод и блок примера — пример и перевод примера (кнопка озвучки — только с `--tts`).
- Обратная карточка: перевод и русский пример как контекст; на обороте — слово, IPA, пример.
- Светлая и тёмная тема, отдельная вёрстка для телефона (до 480px).
- Развёрнутое пояснение в поле перевода (`<br><br><small>…</small>`, только в колодах с HTML)
  показывается мелким серым текстом и скрыто на вопросе RU → …, потому что в нём часто есть ответ.

**Если установлен AnkiConnect** (дополнение `2055492159`, Anki открыт) — примени сам:

```sh
python3 scripts/apply_design.py --model Deutsch --language-field German --code DE
```

`--tts` — только если пользователь попросил озвучку: язык встроенной озвучки Anki для примера
(it_IT, de_DE, fr_FR, es_ES, cs_CZ, pl_PL, en_US…); без опции кнопки нет. На iPhone голоса Siri
недоступны сторонним приложениям; лучший вариант — Premium/Enhanced голос, выбранный в
Settings → Accessibility → VoiceOver → Speech → Rotor Languages. По умолчанию Anki сам проигрывает звук при показе оборота;
выключается в настройках колоды: Audio → Don't play audio automatically.
`--example-transcription-field` — только если пользователь согласился на IPA примера (см. SKILL.md).

Скрипт сначала сохраняет текущие шаблоны и CSS в `backups/`, затем меняет только
шаблоны и стиль: поля, записи и история повторений не затрагиваются. Откат —
`--restore <файл бэкапа>`. Не удаляй шаблоны карточек: вместе с ними удаляются карточки
и их прогресс. После применения проверь вид через `cardsInfo` (отрисованный Anki HTML;
звук там виден как `[anki:play:…]`) и скажи пользователю синхронизировать Anki,
чтобы дизайн появился на телефоне.

**Без AnkiConnect** — выдай пользователю содержимое файлов, заменив метки:
`%WORD%` → `<Язык>`, `%WORD_EX%` → `<Язык> Example`, `%TRANSLATION%` → Russian,
`%TRANSLATION_EX%` → Russian Example, `%IPA%` → Transcription, `%DIR%` → «DE → RU»,
`%RDIR%` → «RU → DE», `%TTS%` → ` {{tts de_DE:German Example}}` или пусто,
`%EXAMPLE_IPA%` → пусто (или блок поля IPA примера, если оно есть). Вставлять: Cards → Front/Back Template каждого шаблона и Styling.

Имена в `{{…}}` должны точно совпадать с именами полей, включая регистр и пробелы.
Пустое поле не создаёт пустой блок. Оформление задаётся шаблоном, а не CSV.
Шаблон применяется ко всем записям этого типа; если тип используется ещё для другой
группы и нужен отдельный вид, сначала клонируй его и примени к нужным записям.

## Импорт

File → Import, выбери CSV. Разделитель (Comma) и HTML (выключен) задаются служебными строками файла — проверь, что Anki их подхватил.
Выбери созданный тип и нужную колоду. Сопоставь поля по именам:

1. `<Язык>`
2. Russian
3. `<Язык> Example`
4. Russian Example
5. Transcription
6. Tags → Tags, если файл создан с `--tags`; иначе Tags → (Nothing).

Служебные строки # не импортируются как карточки; пропускать первую запись не нужно.
При первом импорте N новых записей дают N карточек только при одном шаблоне карточки.
Теги вида `level::B1` в браузере Anki образуют иерархию: по ним можно фильтровать
или создать отфильтрованную колоду (например, `tag:level::B2`).

## Обновление существующих карточек

Не удаляй старые карточки. Используй тот же существующий тип записи и неизменный
первый столбец. Перед обогащением CSV сохрани старые четыре поля побуквенно, если
пользователь просил только добавить IPA. Не исправляй даже пунктуацию первого поля.

Сначала добавь поле Transcription в существующий тип, затем импортируй новый CSV.
Existing notes → Update. Выбери колоду с прежними записями; если доступно,
Match scope → Note Type and Deck ограничит поиск совпадений выбранной колодой.
Match scope → Note Type ищет совпадения во всех колодах этого типа.

Обновление совпавших записей сохраняет расписание повторений. Если все N записей
были импортированы и их первые поля не изменились, ожидаются N обновлений без новых
записей. Фактический результат смотри в отчёте Anki. Не обещай отсутствие дубликатов,
если тип записи или ключи отличаются, или среди исходных записей уже есть дубликаты.

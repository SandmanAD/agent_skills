# anki-language-cards

Навык для AI-агента (Claude Code, Codex): создаёт языковые карточки Anki для любого языка. На выходе — проверенный UTF-8 CSV с переводом, примером, переводом примера и IPA, готовый к импорту. Дизайн карточек можно применить напрямую в Anki через AnkiConnect.

## Возможности

- **Любой язык.** Правила для английского, немецкого, французского, испанского, итальянского, португальского, чешского, польского и общие правила для остальных: артикли, род, формы глаголов, норма произношения, словари для проверки.
- **Четыре сценария:**
  - карточки из своего списка слов;
  - подбор N слов по теме и уровню;
  - слова из песни, текста или субтитров;
  - обновление существующей колоды, например добавление IPA, без дубликатов.
- **Отбор без перекоса по уровню.** Слова любой сложности равноправны, исключаются только устаревшие и редкие. Уровень CEFR ставится тегом, а не служит фильтром.
- **Проверка файла.** Скрипт проверяет число записей, пустые поля, дубликаты, формат IPA и обратное чтение CSV.
- **Готовый дизайн.** Светлая и тёмная тема, вёрстка под телефон, две карточки на слово: язык → русский и русский → язык.

## Формат карточки

| Поле | Пример |
|---|---|
| `German` | das Essen |
| `Russian` | еда |
| `German Example` | Das Essen ist fertig. |
| `Russian Example` | Еда готова. |
| `Transcription` | /das ˈɛsn̩/ |

Имя первого поля — название изучаемого языка. Перевод по умолчанию на русский. Необязательные поля: `Tags` (уровень, тема, источник) и IPA примера (по запросу, для языков с непредсказуемым произношением).

## Установка

Скопируйте папку в каталог навыков агента. Папка должна называться так же, как навык:

```bash
cp -R anki-language-cards ~/.claude/skills/
```

Для Codex описание интерфейса лежит в `agents/openai.yaml`.

**Требования**

- Python 3.8+, без внешних зависимостей.
- Anki 2.1.55+ (импорт CSV со служебными заголовками).
- Необязательно: [AnkiConnect](https://ankiweb.net/shared/info/2055492159) — нужен, чтобы применять дизайн прямо в Anki.

## Использование

Просто попросите агента:

- «Создай 80 немецких карточек A2 для путешествий»
- «Выпиши слова из этой французской песни в карточки»
- «Сделай карточки из этих английских слов, IPA британская: …»
- «Добавь IPA к этому CSV, сохрани четыре старых поля»
- «Примени дизайн к моему типу записи Deutsch»

Агент выдаст CSV и короткую инструкцию по импорту. Если это первый импорт для языка, к ним добавятся шаблоны карточек.

## Скрипты

Агент вызывает их сам. Вручную они нужны только для отладки.

```bash
# JSON с карточками → проверенный CSV для Anki
python3 scripts/export_anki.py cards.json Deutsch.csv --language-field German --expected 100 --tags

# Применить дизайн к типу записи (сначала сохраняется копия шаблонов в backups/)
python3 scripts/apply_design.py --model Deutsch --language-field German --code DE

# Откатить дизайн
python3 scripts/apply_design.py --model Deutsch --restore backups/<файл>.json
```

Все опции — в `--help` каждого скрипта.

## Структура

```
SKILL.md                  инструкции для агента
agents/openai.yaml        интерфейс для Codex
assets/design/            шаблоны карточек и CSS
references/languages.md   особенности языков
references/anki-import.md импорт, дизайн, обновление колоды
scripts/export_anki.py    сборка и проверка CSV
scripts/apply_design.py   применение дизайна через AnkiConnect
```

## Ограничения

- Скрипты проверяют структуру файла, но не язык. Переводы и IPA агент вычитывает отдельно.
- CSV не создаёт тип записи и шаблоны. Их нужно создать один раз вручную (см. `references/anki-import.md`) или применить через AnkiConnect.
- `apply_design.py` меняет только шаблоны и CSS. Поля, записи и прогресс повторений он не трогает.
